# 诗词大会

独立入口 `/poetry/index.html`，大厅游戏 ID `gamelink-poetry`，人数上限 4。无房间参数时单人练习。

1000 道诗词填空题，每场从中随机抽取 15 道不重复题目，协调者生成并同步完整题序，支持鼠标、触摸及触控笔书写。提交后锁定当前答案，画布由封存状态覆盖，只同步带随机 nonce 的 SHA-256 摘要和已交卷状态。固定每题参与者，中途加入下一题参与；退出的成员从本题等待名单移除。

全部仍在房间的本题玩家提交后，统一进入揭晓阶段，各客户端发送笔迹分片。接收方校验摘要，协调者收齐有效笔迹后公开结果，默认 5 秒自动进入下一题。笔迹无自动识别和判分，玩家对照标准答案查看。第 15 题揭晓后结束本场，可点击“再来一场”重新抽取 15 题。题库来源与许可见 QUESTION_SOURCES.md。

成员按 ID 统一选举协调者，断线重连时请求房间状态，提交及揭晓阶段会重发数据。依赖现有 P2P 连接；未退出但无法连接的玩家会阻止完成本题，界面展示每位玩家提交状态。没有服务器权威裁判，前端题库可被开发者工具读取，适用于朋友之间的休闲比赛。

答题记录只在本次会话中保留，提交前的草稿不会通过网络发送。HTTP 非安全上下文不提供 Web Crypto，需要 HTTPS 或 localhost。生产站点为 HTTPS。

构建：`npm run build --prefix game_web`。
