# 午夜街头竞速

独立页面：`public/street-racer/index.html`；大厅游戏 ID：`gamelink-street-racer`，人数上限 4。无需房间参数可单人试驾；从大厅或邀请路由传入 `gameid`、`room`、`username` 后加入 GameLink 房间。

Three.js 提供可切换的第三人称追车与车内第一人称视角、程序生成跑车、霓虹城市和闭合赛道。三圈个人计时，按顺序经过 16 个扇区才能计圈。四辆交通车沿赛道行驶，碰车和撞护栏会减速。多人通过 `street-car` P2P 消息同步位置、朝向、车速、圈数、行驶距离和氮气状态；不是服务器权威竞赛，同房各自出发、独立计时。

PC：W 油门；S 刹车，停下后倒车；A/D 转向；Enter 油门与氮气加速；C 切换视角；Esc 暂停。

手机：横屏握持，点击“启用陀螺仪 · 出发”申请传感器权限；收到传感器数据后，以当前握姿校准零位。支持横屏两种方向，在屏幕旋转后重新校准。赛车中右侧显示加速按钮，右上角可切换视角，按住加速并在车速足够时释放氮气，松手滑行减速。双击赛道可暂停；暂停面板允许重新校准、邀请、音效开关和返回大厅。竖屏、切后台或失去焦点时暂停并清除输入。

方向传感器需要 HTTPS；iOS 的权限申请必须由用户点击触发。未获得权限或没有传感器时，进场面板可以改选触摸转向：左下角显示摇杆，左右拖动转向，松手回正，可与加速同时操作。浏览器允许时尝试进入全屏并锁定横屏，不支持锁定的浏览器需用户自行横握手机。陀螺仪实际方向和驾驶手感仍需真机检查。

资源全部由代码生成，无额外车辆或城市模型下载。标题描述街头竞速玩法，车辆、赛道和素材为本项目原创。

构建：在 `game_web` 执行 `npm run build`。生成完整独立目录 `public/street-racer/assets/`，生产站点输出到 `dist/street-racer/`。

桌面调试手机控件布局时可在入口后附加 `?controls=touch` 或 `?controls=gyro`，正常入口自动检测手机触控设备。
