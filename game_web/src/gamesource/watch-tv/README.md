# 小小小剧院

入口：`public/watch-tv/index.html`，游戏 ID：`gamelink-watch-tv`，人数上限：4。

- 原生 video 控件提供播放、暂停、进度、倍速、音量和全屏。音量与全屏各自独立。
- 换片弹窗支持 HTTP(S) 视频直链、浏览器原生视频和 HLS m3u8（原生 HLS 优先，否则使用 hls.js）。
- 可靠 P2P 消息同步片源、播放状态、进度和倍速。逻辑计数器和成员 ID 处理同时操作的冲突；新成员连接后请求快照，排序首位成员定期重发快照。
- 根据快照时间推算播放位置，偏差超过 0.8 秒时纠正；直播只在可寻址窗口内定位。设备时钟差异和各自视频源加载速度会影响同步精度。
- 自动播放被阻止时点击按钮解锁播放；退出销毁 HLS 和 SDK。
- 所有人分别访问视频源，P2P 只传控制状态，不转发视频。HLS 源须允许跨域。RTMP/RTSP 和需要平台登录的受保护地址无法作为视频直链使用。
- 网页模式使用 iframe，允许全屏，选择片源后尝试全屏，也提供手动全屏和新窗口入口。同步网页地址和模式，不同步第三方页面播放进度。内置泰坦尼克号 Disney+ 页面；其播放和嵌入能力取决于平台、地区及账号权限。
- 不含 room 参数时可预览单人客厅。

构建：`npm run build --prefix game_web`。未进行真实多设备同步验证。

## 内置直播频道

`channels.json` 保存目前核查通过的广东卫视、河北卫视。详细结果和排除的候选源见 `CHANNEL_SOURCES.md`。直播不提供进度条或倍速，不同步绝对秒数；仍可同步换台、播放和暂停。手动片源可勾选直播模式，HLS 直播会自动识别。

## 像素客厅

沙发区由 `PixelLounge.vue` 的 320×180 Canvas 绘制，包含木地板、四座沙发、地毯、盆栽、落地灯和像素角色。

- 点击地板移动；点击空沙发座位会走到座位前坐下。沙发、植物、灯和房间边缘有碰撞。
- 不显示房间下方控制区、成员列表或说明，仅使用点击移动与入座。
- 入座后使用独立的弯腿坐姿，双脚落在坐垫前；点击空座位会自动走过去坐下。
- 角色位置、方向、移动状态和座位以可靠 P2P 消息同步，移动最多每秒 10 次，静止每 2 秒补发快照。
- 重连与新成员会请求快照。序号和会话时间避免旧消息覆盖新位置；同时入座冲突由成员 ID 决定先后，另一人起身。
- 像素客厅不改变播放器状态协议。构建通过，已查看单人布局，未进行多设备位置同步验证。

## 片源自动识别

默认自动识别：扩展名为 mp4/webm 等使用 video，m3u8 使用原生 HLS 或 hls.js，HTML 使用 iframe。无扩展名地址通过最多 4 秒的 HEAD 请求读取 Content-Type，识别视频 MIME 和 HLS MIME；跨域或网络限制无法识别时按网页打开。可手动指定模式纠正识别结果。识别出的模式及 HLS 标记随房间状态一起同步。
