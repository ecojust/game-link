# 狂野炉石

入口 `/wild-hearth/index.html`，游戏 ID `gamelink-wild-hearth`，至少两人开局，人数上限 4。2–4 人自由混战，无身份、无阵营，最后存活者获胜。无房间参数时开启三位电脑对手的单人练习。

## 规则

30 生命，起手四张，54 种卡池（30 随从、24 法术），统一公共牌堆 108 张（54 种卡各两张）。每回合增加一枚法力水晶，最多 10，恢复法力并抽一张；最多 10 手牌和 5 随从。随从召唤当回合不能攻击，冲锋除外；攻击随从双方同时受伤。嘲讽限制随从攻击，法术和英雄技能可以绕过。职业技能消耗 2 法力，每回合一次。回合 60 秒，超时结束；公共牌堆用尽会受到递增疲劳伤害。淘汰者可观战。

## 同步

等待阶段按成员 ID 选定裁定客户端，开局后固定。其他客户端只提交带版本号的操作，由裁定端检查行动顺序、目标、法力、随从状态。分别单播视图，只发送接收者自己的手牌，其他人仅收到手牌数量；所有英雄信息公开。每三秒重发视图，连接恢复请求快照。裁定客户端保存完整局面到 sessionStorage，其他客户端保存自己的视图及裁定者 ID，支持同一标签页刷新恢复。存活玩家或裁定者断线时暂停计时与操作；当前版本需要原玩家回来，不能由另一个设备替代。P2P 裁定端可信，不提供竞技级防作弊或裁定端迁移。

构建 `npm run build --prefix game_web`。尚未进行真实四设备联机验证。

## 四个职业与卡池

开局前可选铁卫战士、星焰法师、荒野猎手、晨光牧师；允许重复职业。技能分别为 3 护甲、1 点指定敌方伤害、2 点敌方英雄伤害、3 点任意角色治疗，均 2 法力每回合一次。单人练习可通过顶部职业按钮回到选择界面。

不构筑个人牌组：54 种卡各两张组成公共随机牌堆，由裁定客户端洗牌和发牌。每位玩家起手四张，轮到某人时仅该玩家自动抽一张；抽牌法术及战吼/亡语额外抽牌仍正常触发。所有职业可以抽取并使用所有卡牌，职业仅决定英雄技能。卡牌的职业标签表示风格，不限制使用。图鉴保留风格筛选。

公共牌堆顺序仅保存在裁定客户端，单播视图只公布剩余张数；各玩家手牌仅发送本人。公共牌堆耗尽后，各玩家自己的疲劳伤害次数分别累加。没有每轮给全体发牌，也不会在一回合内重复自动发牌；重连快照不会再次发牌。

护甲先吸收伤害；圣盾抵消下一次正伤害；冻结阻止当前和下回合攻击；战吼入场触发、亡语死亡触发。英雄死亡时清空其随从，停止其亡语。增益同时增加随从攻击、当前和最大生命。疲劳伤害可由护甲吸收。新状态使用 v4 缓存键，避免旧版状态字段不兼容。

## 卡牌插画

54 张卡牌各有一张由内置 imagegen 单独生成的原创插画，手牌、图鉴与场上随从通过 `cardArt(id)` 共用。网页资源位于 `game_web/public/wild-hearth/card-art/<id>.jpg`，最长边 512 像素，采用 JPEG 压缩和懒加载。原始 PNG 与逐卡提示词保存在仓库根目录 `output/imagegen/wild-hearth-cards/`，便于后续更新。

## 桌面战场交互

宽屏鼠标设备使用牌桌布局与扇形手牌：拖动随从牌到己方战线召唤；无目标法术拖入战场释放；有目标法术、可指定目标的英雄技能和可攻击的随从拖向高亮目标，松开执行。绿色落点表示合法目标，无效位置松开、Esc、窗口失焦、回合或连接状态变化都会取消拖动，不提交操作。法力不足、战线已满、冻结或未就绪时无法开始相应拖动。

悬停手牌和随从可查看放大牌面，牌桌显示敌方手牌背面、生命、护甲、法力水晶以及圣盾、嘲讽与冻结状态。局面更新驱动召唤、攻击位移、伤害、治疗、破盾、死亡和回合提示；不更改裁定规则或网络消息。手机继续使用点选操作，键盘与桌面点选也保留。
